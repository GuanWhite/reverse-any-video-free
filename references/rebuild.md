# 分层重建与匹配配方

上游的"每一层"策略按元素类型路由；本 skill 保留全部**免费**策略，把依赖 HeyGen/额度的两种改成离线降级。匹配方法、测量口径与 CSS/SVG 配方改编自上游 `references/match.md`（Apache-2.0），这些内容本身不需要任何账号，全部原样保留。

## 1. 按元素类型路由

| 元素 | 上游做法 | 本 skill 做法 | 可编辑性 |
| --- | --- | --- | --- |
| 文字、字幕、贴纸、卡片、UI、录屏、图表、地图 | HTML 重建 | **相同**，HTML/CSS/SVG 重写 | 高 |
| 照片、专辑封面、Logo、App 图标、照片里的人、拼贴 | 从原帧按自己的框裁切 | **相同**；Logo 取画面中最大的那次出现或用品牌原始素材，绝不手绘 | 中（可替换素材） |
| 出镜人物 | HeyGen 以原片为 motion guide **重拍**（Pro + credits） | **免费降级**：按人物框裁切原镜头片段、静音、作为子素材；跨跳切处必须切断 | 中低（原片素材） |
| 动画 / 手绘 / 3D / 复杂实拍整镜 | 生成式整镜重绘（Pro + credits） | **免费降级**：层拆不开的镜头整镜裁切，明确标记为「不可编辑片段」 | 低 |
| 全片背景 | 禁止整帧播放原片 | **相同禁令** | — |

### 人物免费降级的边界

裁切原片人物意味着：原片烧录在人物区域内的字幕会一起带过来、原片的脸会保留、口型与原音轨天然一致（这点是优势）。因此：

- 先按镜头切点切断，一个裁切片段绝不跨跳切；
- 若文字穿过人物，优先把文字层重建在人物**之上/之下**能遮盖的位置，或标注为已知近似；
- 生成式重拍能做到的"换掉原脸、抹掉烧录字"在本 skill 中做不到，必须写进 `REVERSE_FREE.md` 与最终交付说明；
- 涉及真人肖像与第三方素材时，确认使用者有相应授权。

### 整镜降级的边界

`animated.md` 原本就承认：手绘/3D 片里角色、世界、相机是同一张画，层分不开。免费版不生成新画面，只做两件事：把**能用代码承载的部分**（文字、手写、Logo、尾板、叠加光效、静止世界上的相机运动）重建为可编辑层，其余整镜裁切并在报告中逐镜列出。生成式镜头本来也只是"可替换的 clip、不是可改的层"，所以可编辑性损失有限，但**画面内容不再与原片解耦**。

## 2. 决定"像不像"的匹配方法

### 时序

- 图形在**精确帧**上变化：第 241 帧完全出现就 `set` 到第 241 帧，不要淡入；只有亲眼看到连续几帧在动的才 tween。相机一帧落位也是 `set`。
- 字幕：每组首末帧从**字幕带像素**取（`cuts.py --roi ...`），每帧都看；文字内容可另用本地转写，但切换时刻以像素为准。字幕常领先/滞后人声。除非原片淡变，否则硬切。
- 切点处的模糊闪、溶解、擦除是切点的一部分，按量到的帧数重建。

### 字号、字体、位置

- **按墨迹量字号，不靠眼睛**：裁原帧里那一行，与自建帧同一行对比 ink box 的高和宽，先调 `font-size`，再调 `letter-spacing`，直到两者相差几像素内；替换字体通常更宽，数字也要单独比。再比较墨色深浅定字重，看有没有描边或阴影。
- 按字形特征（几何、对比、x-height、末端）选字体族，在量好的字号上试 2–3 个候选；优先内置字体，其次放进 `assets/fonts/` 的免费可分发字体。**替换了哪个字体必须写进 `REVERSE_FREE.md`**。
- 位置取自原图像素里量到的框。画布尺寸就是原片尺寸，所以量到多少就写多少。

### 外观

- 动效片里背板占画面大部分：在多个时刻对空白背板取网格采样，匹配它的渐变与亮度随时间的变化。
- 原片里的快速运动是**带运动模糊**的；高速下锐利的图块会被判为错。运动快时沿运动方向模糊（配方见下）。
- 点阵/像素纹理：从一帧量出格子（间距、偏移、颜色），按这个网格渲染，不要目测。
- 像素材一样运动的平面图形（镜头下的地图、滚动的示意图）：把每块板描成平色形状并拟合镜头运动，比从外部数据重画准得多。

## 3. 可直接复用的配方（纯 CSS / SVG，零账号）

这些是 `match.md` 中"过往丢分点"固化下来的实现，本 skill 完整保留。

**扫光填充**：两份同样的文字，点亮的那份在上面，`clip-path: inset(0 100% 0 0)` 按量到的时间与方向 tween 到 `inset(0 0 0 0)`。

```css
.word-lit { clip-path: inset(0 100% 0 0); }  /* tween to inset(0 0 0 0) */
```

**渐变字**：`background: linear-gradient(...)` + `background-clip: text` + 透明填充。

**玻璃字压在素材上**（字里显示被折射的底层画面，暗边+亮边）：把镜头画面再复制一份，用含 `<text>` 的 SVG `<clipPath>` 裁进字形，经 `feTurbulence`（`baseFrequency` 约 0.02，固定 seed）→ `feDisplacementMap`（scale 40–60）扭曲；其上叠一份暗色文字以 15–35% 正片叠底、2–3px 深色描边、顶部亮边。这一组放在镜头的 camera group 里。

**描边字**：量到的宽度写 `-webkit-text-stroke`，填充透明。

**方向性运动模糊**：在移动的 wrapper 上用 SVG `<filter>`，tween `stdDeviation`（`"24 0"` 是横向拖影）。**CSS `blur()` 是对称的，这里是错的**。

**残影**：沿运动方向放 2–4 个克隆，透明度约 0.5 / 0.3 / 0.15。

**发光**：叠 `text-shadow` 或 `drop-shadow`，tween 半径与 alpha。

**遮罩与擦除**：`clip-path` 或 `mask-image` 配一个被 tween 的 stop。

**闪白**：整帧图层，只活量到的那几帧。

**颗粒**：SVG `feTurbulence` 固定 seed，每帧步进。注意**颗粒必然拉低 SSIM/PSNR**：匹配"观感"，不要追像素分数。

## 4. 重建顺序建议

1. 先按 `cuts.json` 把镜头骨架与时长搭好，音轨直挂；
2. 背板、大色块、镜头运动；
3. 大文字（每个都先读它的一生）与主要图形；
4. 子素材：按框裁切、按出现时间摆放；
5. 字幕组与 UI 细节；
6. 转场、模糊、闪白、颗粒等"最后一公里"效果；
7. 渲染 → `diff.py` → 只修一轮。

不要在骨架还没对齐时精修字号；时间是所有误差里最贵的一种。
